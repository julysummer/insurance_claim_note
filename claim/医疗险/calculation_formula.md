# 医疗险理赔计算公式

按保障范围分为：百万医疗险、中端医疗险、小额医疗险、门诊医疗险

---

## 一、可赔基数计算规则

### 核心原则
```
有医保：基数 = 个人现金支付(ownPayAmount)
无医保：基数 = 发票总金额(totalAmount)

个人现金支付 = 发票总金额 - 医保统筹 - 个账支付 - 其他支付
```

### 特殊处理：个人现金支付为0
- 当个人现金支付<=0时，使用发票总金额作为基数
- 原因：可能全额医保报销，或数据异常

### 字段来源（发票Schema）
| 字段 | 中文名 | 说明 |
|------|--------|------|
| totalAmount | 发票总金额 | 本次花费总额 |
| fundPayAmount | 医保统筹基金支付 | 医保报销部分 |
| accountPayAmount | 个人账户支付 | 医保卡余额扣款 |
| ownPayAmount | 个人现金支付 | 本人实际付款 |
| selfPaymentAmount | 个人自付 | 医保范围内自付 |
| selfPaymentCost | 个人自费 | 医保范围外自费 |
| isMedicalInsurance | 是否医保票据 | 0-否，1-是 |

### 判断逻辑
```
if 发票.是否医保 == "1":
    if 个人现金支付 > 0:
        可赔基数 = 个人现金支付
    else:
        可赔基数 = 发票总金额
else:
    可赔基数 = 发票总金额
```

## 二、通用计算公式

```
最终赔付 = MIN( 初步赔付, 单次限额, 年度剩余限额 )
初步赔付 = MAX(0, 可赔基数 - 免赔额) × 赔付比例

其中：
- 年度剩余限额 = 年度限额 - 年度已赔
```

### 计算步骤
```
步骤1：确定可赔基数（根据医保类型）
步骤2：扣除除责项目金额
步骤3：扣除免赔额（支持分段免赔）
步骤4：计算初步赔付
步骤5：检查项目限额（可选）
步骤6：应用单次限额
步骤7：应用年度限额
```

---

## 三、除责项目扣减

### 处理逻辑
- 从可赔基数中直接扣除除责项目的费用
- 除责项目来源：牙科、美容整形、康复理疗等

### 公式
```
可赔基数 = 个人现金支付 - 除责项目金额
```

### 示例
| 发票金额 | 现金支付 | 除责项目(牙科) | 可赔基数 | 最终赔付 |
|----------|----------|----------------|----------|----------|
| 5000 | 2000 | 500 | 1500 | 1500 |
| 3000 | 3000 | 0 | 3000 | 3000 |

## 四、分段免赔

### 概念
不同费用区间适用不同的免赔额

### 配置示例
```json
{
  "tiered_deductible": [
    {"min": 0, "max": 1000, "deductible": 100},
    {"min": 1000, "max": 5000, "deductible": 200},
    {"min": 5000, "max": "inf", "deductible": 500}
  ]
}
```

### 示例
| 可赔基数 | 适用区间 | 免赔额 | 扣减后 |
|----------|----------|--------|--------|
| 500 | 0-1000 | 100 | 400 |
| 3000 | 1000-5000 | 200 | 2800 |
| 10000 | 5000以上 | 500 | 9500 |

---

## 五、项目限额

### 概念
部分项目有限额（如特定药品、检查项目）

### 公式
```
最终项目扣减 = MAX(0, 项目费用 - 项目限额)
```

### 配置示例
```json
{
  "item_limits": {
    "中药": 500,
    "检查费": 1000,
    "特定药品": 2000
  }
}
```

## 六、各产品公式

### 1. 百万医疗险
```
最终赔付 = MIN( MAX(0, 个人现金支付 - 10000) × 100%, 单次限额, 年度限额 - 已赔 )
```
- **免赔额**：1万/年（年度累计）
- **仅住院**
- **示例**：
  - 现金支付5000元 → (5000-10000)×100% = 0（不赔付）
  - 现金支付20000元 → (20000-10000)×100% = 10000元

### 2. 中端医疗险
```
最终赔付 = MIN( 基数 × 100%, 单次限额, 年度限额 - 已赔 )
```
- **免赔额**：0
- **覆盖**：门诊 + 住院

### 3. 小额医疗险
```
最终赔付 = MIN( 基数 × 100%, 单次限额, 年度限额 - 已赔 )
```
- **免赔额**：0
- **年度限额**：1-5万

### 4. 门诊医疗险
```
最终赔付 = MIN( 基数 × 100%, 每日限额, 年度限额 - 已赔 )
```
- **免赔额**：0
- **特殊**：按日限额

## 七、计算示例

### 示例1：百万医疗险（有医保）
| 项目 | 值 |
|------|-----|
| 发票总金额 | 50000 |
| 医保统筹 | 35000 |
| 个账支付 | 2000 |
| 现金支付 | 13000 |
| 免赔额 | 10000 |
| 年度已赔 | 0 |

**计算：**
1. 基数 = 13000（个人现金支付）
2. 扣减免赔 = 13000 - 10000 = 3000
3. 初步赔付 = 3000 × 100% = 3000
4. 年度剩余 = 300万 - 0 = 300万
5. 最终赔付 = **3000元**

---

### 示例2：有除责项目
| 项目 | 值 |
|------|-----|
| 发票总金额 | 8000 |
| 医保统筹 | 6000 |
| 现金支付 | 2000 |
| 除责项目(牙科) | 500 |
| 免赔额 | 10000 |

**计算：**
1. 基数 = 2000
2. 扣减除责 = 2000 - 500 = 1500
3. 扣减免赔 = 1500（负数取0）= 0
4. 初步赔付 = 0
5. 最终赔付 = **0元**

---

### 示例3：分段免赔
| 费用区间 | 免赔额 |
|----------|--------|
| 0-1000 | 100 |
| 1000-5000 | 200 |
| 5000以上 | 500 |

| 可赔基数 | 适用区间 | 免赔额 | 扣减后 |
|----------|----------|--------|--------|
| 500 | 0-1000 | 100 | 400 |
| 3000 | 1000-5000 | 200 | 2800 |
| 10000 | 5000+ | 500 | 9500 |
