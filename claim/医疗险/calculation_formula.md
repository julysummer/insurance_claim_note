# 医疗险理赔计算公式

适用于：门诊医疗险、住院医疗险、慢特病门诊医疗险

---

## 核心公式

```
最终赔付 = MIN( 初步赔付, 单次限额, 年度剩余限额 )

初步赔付 = MAX(0, 可赔基数 - 免赔额) × 赔付比例
```

---

## 可赔基数

| 医保状态 | 可赔基数 | 说明 |
|----------|----------|------|
| 医保已结算 | `个人现金支付(ownPayAmount)` | 医保报销部分不重复 |
| 医保未结算 | `发票总金额(totalAmount)` | 全额计算 |

---

## 计算步骤

### 步骤1：确定可赔基数
```
有医保：基数 = 个人现金支付
无医保：基数 = 发票总金额
```

### 步骤2：扣除免赔额
```
可赔金额 = MAX(0, 基数 - 免赔额)
```

### 步骤3：计算赔付
```
初步赔付 = 可赔金额 × 赔付比例
```

### 步骤4：应用限额
```
最终赔付 = MIN(初步赔付, 单次限额, 年度限额-已赔)
```

---

## 详细示例

### 示例1：门诊（有医保）

**输入参数：**
| 参数 | 值 |
|------|-----|
| 发票总金额 | 580元 |
| 医保统筹支付 | 400元 |
| 个人账户支付 | 50元 |
| 个人现金支付 | 130元 |
| 免赔额 | 100元 |
| 赔付比例 | 80% |
| 单次限额 | 2000元 |
| 年度限额 | 5000元 |
| 年度已赔 | 0元 |

**计算过程：**

| 步骤 | 计算 | 结果 |
|------|------|------|
| 1. 确定基数 | 130元（个人现金支付） | 130元 |
| 2. 扣减免赔额 | 130 - 100 = 30 | 30元 |
| 3. 初步赔付 | 30 × 80% = 24 | 24元 |
| 4. 单次限额 | MIN(24, 2000) | 24元 |
| 5. 年度限额 | MIN(24, 5000-0) | **24元** |

**结果：赔付 24 元**

---

### 示例2：住院（高费用，有医保）

**输入参数：**
| 参数 | 值 |
|------|-----|
| 发票总金额 | 15000元 |
| 医保统筹支付 | 12000元 |
| 个人账户支付 | 500元 |
| 个人现金支付 | 2500元 |
| 免赔额 | 10000元（百万医疗） |
| 赔付比例 | 100% |
| 单次限额 | 100万元 |
| 年度限额 | 300万元 |
| 年度已赔 | 0元 |

**计算过程：**

| 步骤 | 计算 | 结果 |
|------|------|------|
| 1. 确定基数 | 2500元 | 2500元 |
| 2. 扣减免赔额 | 2500 - 10000 = 0（负数取0） | 0元 |
| 3. 初步赔付 | 0 × 100% = 0 | 0元 |
| 4. 限额检查 | MIN(0, 100万, 300万) | **0元** |

**结果：不赔付（需自付免赔额）**

---

### 示例3：住院（无医保）

**输入参数：**
| 参数 | 值 |
|------|-----|
| 发票总金额 | 20000元 |
| 医保统筹支付 | 0元 |
| 个人现金支付 | 20000元 |
| 免赔额 | 500元 |
| 赔付比例 | 80% |
| 单次限额 | 50000元 |
| 年度限额 | 100000元 |
| 年度已赔 | 30000元 |

**计算过程：**

| 步骤 | 计算 | 结果 |
|------|------|------|
| 1. 确定基数 | 20000元（发票总金额） | 20000元 |
| 2. 扣减免赔额 | 20000 - 500 = 19500 | 19500元 |
| 3. 初步赔付 | 19500 × 80% = 15600 | 15600元 |
| 4. 单次限额 | MIN(15600, 50000) | 15600元 |
| 5. 年度限额 | MIN(15600, 100000-30000) | **15600元** |

**结果：赔付 15600 元**

---

## 速查表

| 场景 | 公式 |
|------|------|
| 有医保 | `MIN((个人现金支付-免赔额)×比例, 单限, 年限-已赔)` |
| 无医保 | `MIN((总金额-免赔额)×比例, 单限, 年限-已赔)` |
