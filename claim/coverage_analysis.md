## 四、反思：当前规则的问题

### 4.1 覆盖不全面

- **问题**：仅覆盖4个基础险种
- **影响**：其他险种产品无法使用规则引擎

### 4.2 规则粒度

- **问题**：规则较为通用，未针对具体产品细分
- **改进**：可根据 insuranceType 自动选择规则引擎

### 4.3 除外责任

- **问题**：除外关键词库可能不完整
- **改进**：需持续补充维护

### 4.4 动态参数

- **问题**：部分参数如免赔额类型（年免赔/次免赔）未完全实现逻辑
- **改进**：需完善年免赔计算逻辑

## 五、建议扩展

### 5.1 险种自动选择

```python
def get_engine(insurance_type: str):
    """根据险种自动选择规则引擎"""
    engine_map = {
        "医疗险": MedicalClaimEngine,
        "意外险": AccidentClaimEngine,
        "重疾险": CriticalIllnessClaimEngine,
        "寿险": LifeClaimEngine,
    }
    return engine_map.get(insurance_type)
```

### 5.2 新增险种建议

建议后续扩展的优先级：

1. **住院津贴险** - 已部分含在意外险，可独立
2. **护理险** - 失能护理需求增加
3. **孕产险** - 生育保险需求
