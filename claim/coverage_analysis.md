# 理赔规则字段映射与覆盖分析

## 一、当前字段覆盖情况

### 1.1 已覆盖的数据源

| 数据源 | 字段数 | 说明 |
|--------|--------|------|
| 保单信息 | 8个 | policyNumber, policyStartDate 等 |
| 发票信息 | 21个 | totalAmount, ownPayAmount 等 |
| 理赔申请 | 3个 | accidentDate, reportDate 等 |
| 条款配置 | 15+个 | 免赔额、等待期、赔付比例等 |

### 1.2 条款解析（从保险条款提取）

| 条款字段 | 来源 | 用途 |
|----------|------|------|
| product_type | 条款.产品名称 | 区分百万/中端/小额/门诊医疗险 |
| claim_type | 条款.理赔类型 | 给付型/报销型/津贴型 |
| deductible_type | 条款.免赔额类型 | 累计/不累计/无免赔 |
| disease_waiting_period | 条款.疾病等待期 | 天数 |
| reimbursement_category | 条款.报销类别 | 门诊/住院/急诊 |

### 1.3 可赔基数计算规则

```
险种判断（从条款product_name或claim_type）：
  ├─ 百万医疗险 → 基数=个人现金支付，免赔1万/年
  ├─ 中端医疗险 → 基数=个人现金支付或发票总额，0免赔
  ├─ 小额医疗险 → 基数=个人现金支付或发票总额，0免赔
  └─ 门诊医疗险 → 基数=个人现金支付或发票总额，0免赔，有日限

医保判断（从发票isMedicalInsurance）：
  ├─ 有医保("1") → 基数 = ownPayAmount（个人现金支付）
  └─ 无医保("0") → 基数 = totalAmount（发票总金额）
```

## 二、当前规则覆盖的险种

| 险种 | 规则状态 | 核心逻辑 |
|------|----------|----------|
| 医疗险 | ✅ 已完成 | 费用报销（免赔额+比例） |
| 意外险 | ✅ 已完成 | 意外医疗+身故+伤残+津贴 |
| 重疾险 | ✅ 已完成 | 确诊即赔 |
| 寿险 | ✅ 已完成 | 身故赔付 |

### 2.1 医疗险细分（按保障范围）

| 产品 | 核心公式 | 免赔额 | 年度限额 | 门诊 | 住院 | 等待期 |
|------|----------|--------|----------|------|------|--------|
| 百万医疗险 | MIN((基数-1万)×100%, 单限, 年限-已赔) | 1万/年 | 300万 | ❌ | ✅ | 30天 |
| 中端医疗险 | MIN(基数×100%, 单限, 年限-已赔) | 0 | 200万 | ✅ | ✅ | 30天 |
| 小额医疗险 | MIN(基数×100%, 单限, 年限-已赔) | 0 | 5万 | ✅ | ✅ | 30天 |
| 门诊医疗险 | MIN(基数×100%, 日限, 年限-已赔) | 0 | 1万 | ✅ | ❌ | 7天 |

#### 公式说明

```
百万医疗险（住院）：
  公式：MIN((个人现金支付-10000)×100%, 单次限额, 年度限额-已赔)
  重点：1万年免赔额，仅住院报销

中端医疗险（门诊+住院）：
  公式：MIN(基数×100%, 单次限额, 年度限额-已赔)
  基数：有医保=个人现金支付，无医保=发票总金额

小额医疗险（门诊+住院）：
  公式：MIN(基数×100%, 单次限额, 年度限额-已赔)
  特点：0免赔额，保额低（1-5万），适合小病

门诊医疗险（仅门诊）：
  公式：MIN(基数×100%, 每日限额, 年度限额-已赔)
  特点：0免赔额，按日限额控制
```

## 四、反思：当前规则的问题

### 4.1 覆盖不全面

- **问题**：仅覆盖4个基础险种
- **影响**：其他险种产品无法使用规则引擎

### 4.2 规则粒度

- **问题**：规则较为通用，未针对具体产品细分
- **改进**：可根据 insuranceType 自动选择规则引擎

### 4.3 除外责任

- **问题**：除外关键词库可能不完整
- **改进**：需持续补充维护

### 4.4 动态参数

- **问题**：部分参数如免赔额类型（年免赔/次免赔）未完全实现逻辑
- **改进**：需完善年免赔计算逻辑

## 五、建议扩展

### 5.1 险种自动选择

```python
def get_engine(insurance_type: str):
    """根据险种自动选择规则引擎"""
    engine_map = {
        "医疗险": MedicalClaimEngine,
        "意外险": AccidentClaimEngine,
        "重疾险": CriticalIllnessClaimEngine,
        "寿险": LifeClaimEngine,
    }
    return engine_map.get(insurance_type)
```

### 5.2 新增险种建议

建议后续扩展的优先级：

1. **住院津贴险** - 已部分含在意外险，可独立
2. **护理险** - 失能护理需求增加
3. **孕产险** - 生育保险需求
